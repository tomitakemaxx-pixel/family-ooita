# 大分 家族旅行 プラン作成 引き継ぎ資料

**作成日：** 2026年9月12日（土）
**読み手：** Claude Code
**この資料の目的：** 大分（別府・湯布院）への家族4人旅行について、**行くかどうかを判断するための日程案・費用案を作り、決まったあとは旅のしおりを作る**ための前提を渡すこと
**使う場面：** 九州ふっこう応援割の予約受付が始まる2026年9月下旬までに日程を決める必要があり、その検討と、決定後のしおり作成に使う

## 0. 最初に読むべき3点

1. **まだ「行く」と決まっていない。** 検討段階であり、行き先・日程・泊数・予算のいずれも未確定（第Ⅰ章）
2. **期限がある。** 九州ふっこう応援割は**12月25日宿泊分まで**で、大分県の予約受付開始は**9月下旬予定**。予算切れ次第終了のため、実質的に受付開始直後が勝負（第Ⅲ章）
3. **未確認事項が多い。** 本資料の事実には確認日と出典を付けてある。付いていない記述は未確認であり、**成果物に断定で書く前に公式サイトで確認すること**（第Ⅷ章）

## Ⅲ. 九州ふっこう応援割 ── 確認済み事実

### (1) 制度の骨格

2026年7月28日に発生した令和8年熊本地震（Mj7.1、熊本県宇城市・八代郡氷川町で最大震度7）を受け、**2026年8月28日に観光庁・国土交通省が発表**した旅行支援策。

| 項目 | 内容 |
|---|---|
| 補助率 | 旅行・宿泊料金の50%（熊本県・鹿児島県のみ60%） |
| 上限（1予約1人あたり） | 宿泊単体1泊＝2.0万円／交通付宿泊1泊＝2.0万円／交通付宿泊2泊以上＝3.0万円／宿泊地が2県以上の周遊型＝3.5万円 |
| 対象期間（大分県） | **2026年10月1日〜12月25日宿泊分** |
| 予約受付開始（大分県） | **9月下旬予定**（2026年9月3日に関連予算が成立） |
| 対象県 | 九州7県すべて |
| 財源 | 国の予備費（報道により151億円／155億円と幅がある。確定額は未確認） |
| 重要な条件 | **予約受付開始前に取った予約は対象外**。原則、予約の取り直しになる |
| 終了条件 | 予算上限に達し次第終了 |

**出典：** 観光庁発表（2026年8月28日）、トラベルWatch、補助金ポータル、九州旅行完全ガイド等の2026年9月11日時点のまとめ。いずれも二次情報であり、**大分県の公式発表が出た時点で原文を確認すること**。

### (2) 家族4人での試算

上限が「1人あたり」なので、人数が多いほど効く。

| ケース | 計算 | 割引額 |
|---|---|---|
| 宿のみ・1人1泊1.5万円の宿に4人で1泊 | 総額6万円 × 50% | 3.0万円引き |
| 同・2泊 | 総額12万円 × 50% | 6.0万円引き |
| 航空券＋宿のパッケージで2泊・総額28万円 | 50%＝14万円だが上限3万円×4人で頭打ち | 12.0万円引き |

**設計上のポイント**

- 上限2万円／泊は、**1泊1人4万円を超える宿で頭打ち**になる。高級旅館ほど実質割引率は下がるため、1人1.5〜2万円クラスの宿がもっとも効率がよい
- 交通付（ダイナミックパッケージ）で2泊以上にすると上限が3万円に上がる。**航空券と宿を別々に取るより、パッケージの方が補助の器が大きい**
- 子どもの扱いについて、旅行会社（ニーズツアー）のFAQは「旅行代金の有無にかかわらず0歳児から対象」と案内している。ただし**これは事業者の説明であり、大分県の要項原文では未確認**。予約画面の表示で最終確認が必要

### (3) リスク

- 予算切れによる早期終了。受付開始が9月下旬で対象期間が12月25日までと短いため、**人気宿は開始直後に埋まる想定**
- 対象プランは予約サイトが「九州ふっこう応援割対象」と表示しているものに限られ、同じ宿でも全プランが対象になるとは限らない
- 制度の詳細（併用可否、キャンセル時の扱い）は大分県の発表を待つ必要がある

### (1) 長男（4歳）に刺さる可能性が高いもの

→ **判断基準：動物が実際に動く・触れる・餌をやれる体験を優先し、座って説明を聞く形式は後回し。**

ケアンズで**2日間・4セッション釣って釣果ゼロ**に終わっており、本人から「子どもたちに魚を釣る成功体験をさせたい」という意向が明示されている。

→ **大分で「確実に釣れる」場所を調べること。** 管理釣り場（ニジマス等の釣り堀）、海釣り公園、釣り堀併設の温泉施設など。**幼児2人連れで安全に竿を出せるか**（柵の有無、水面までの高さ、風）を必ず確認する。ケアンズでは強風のため「子どもが海に落ちたら助けられない」と判断して切り上げた経緯がある。

## Ⅸ. 作業の進め方

### (1) 順序

1. 第Ⅷ章の未確認事項を調査する
2. **骨子（日程の枠・行き先・概算費用）を先に提示して、本人と照準を合わせる。** いきなり完成版のしおりを作らない（過去、作り直しコストの高い資料をいきなり本文化して往復が発生した反省がある）
3. 行くかどうか・日程が決まったら、予約作業の時系列表を作る
4. 予約が固まってから、写真付きのしおりを本文化する

### (2) 提示のしかた

- 日程は**複数案を並べて比較できる形**で出す。単一案を推して終わりにしない
- 費用は**レンジで示し、推定であることを明記する**。応援割の適用可否が未確定のうちは、適用あり・なしの両方を出す
- 調べて分からなかったことは「分からない」と書く。**推測で穴埋めしない**

### (3) しおりの書式ルール（プライベート文書）

- 見出し階層は **Ⅰ/Ⅱ/Ⅲ → (1)(2)(3) → ①②③**。「2.1」「3.2.1」の数字ドット形式は使わない
- 「エグゼクティブサマリー」ではなく「**要約**」と書く
- **プライベートの文書なので、色・アイコン・写真は自由に使ってよい**（白黒・無装飾の制約は仕事用のWord文書にのみ適用される）
- 横長の資料を作る場合はWordではなくPowerPointで作る
- ケアンズ・秩父のしおりと同様、**画像を文書内に直接埋め込む**（QRコードで外部参照させる方式は「現場で見返すのが面倒」として却下された実績がある）
- 現地で参照する情報（施設の開園時間、バスの時刻、緊急連絡先）は、**しおりを見れば完結する**ようにまとめる
