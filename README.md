「行くかどうかを判断する」ための資料を管理する。

## 現時点の結論（v3・2026年9月23日更新）

- **行く価値はある。** 日程は **11月20日（金）〜22日（日）**（金曜に有給1日、帰宅翌日の11/23が勤労感謝の日）
- **1泊目 別府・杉乃井ホテル（楽天 5547）／2泊目 湯布院・山のホテル 夢想園（楽天 44815）**
- **2日目・3日目だけレンタカー**（別府駅前で借り、大分空港で乗り捨て）にすると、
  湯布院・地獄めぐり・アフリカンサファリが2泊3日に収まる。3泊4日は不要
- **予約開始は 2026年9月25日（金）12:00**（OTA4サイト）。先行した長崎は20分で完売
- 予約は楽天トラベル ANA楽パック「航空券＋宿泊」、2泊目を「宿泊施設変更」で夢想園に。
  レンタカーは楽パックに付けない（ホーバークラフトと両立しないため）
- **9月25日12時より前に航空券も宿も取らない**（開始前の予約は応援割の対象外）

## 訂正（v3.1・9月23日）

- 宿泊のみの上限は「1人1旅行2万円」（1泊ごとではない）
- 先行した熊本・長崎・佐賀の楽天では、楽パック2泊以上のクーポンは「1名3万円／2名6万円」の定額型のみ
  （無料幼児は含まない、枚数は数十枚）。大分も同じ形なら有料3名の我が家に合うクーポンがない可能性が高い
- → **9/25 11:50に楽天の大分クーポン一覧を見て、3名以上用がなければ最初から宿泊のみ**（夢想園 → 杉乃井の順、じゃらん）。
  航空券はそのあと別に買う。割引の見込みは約11万円ではなく **約6万円**
- 子どもは予約の人数に入れれば「1名」（福岡・佐賀・長崎・熊本が明記）

## 別冊の結論（9月23日）

- 家族で大分の代わりになる県はない。本命は本編の形のまま
- 福岡は「9/25に大分が取れなかったときの受け皿」と「ゆふいんの森で湯布院に入る別ルート（案C）」として意味がある
- 鹿児島は冬の2回目の候補（60%・2027年2月末まで、2泊3日で▲約4.2万）
- 父1人なら熊本（湯らっくす＋黒川温泉、60%）が最有力。佐賀（らかんの湯）は2027年3月の三十路会で行くため今回は不要
- 熊本・長崎は「終わって」いない。熊本は宿の直販を順次拡大中、長崎は9/28から宿の直販
