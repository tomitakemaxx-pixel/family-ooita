「行くかどうかを判断する」ための資料を管理する。

## 現時点の結論（v4・2026年9月23日夜）

- **行く価値はある。** 日程は **11月20日（金）〜22日（日）**（金曜に有給1日、帰宅翌日の11/23が勤労感謝の日）
- **運転はしない。** 杉乃井ホテル（楽天 5547）に2泊し、2日目は路線バスで
  アフリカンサファリ（亀の井バス41系統・46分）→ 帰りに鉄輪で降りて地獄めぐり、
  3日目の午前に湯布院へ寄って、由布院駅前13:40発の直行バスで大分空港へ
- 奥様が湯布院に泊まりたい場合は、2泊目を山のホテル 夢想園（楽天 44815）にする形も併記
- **予約開始は 2026年9月25日（金）12:00**（OTA4サイト）。先行した長崎は20分で完売
- 9/25は、楽天の楽パック2泊以上のクーポンが**3名以上で使えるなら楽パック、なければ宿泊のみ（じゃらん）**。
  先行県の楽天では1名用・2名用の定額クーポンしかなかった（v3.1で判明）
- 割引の見込みは約5.5〜6万円（宿泊のみ・上限は1人1旅行2万円）
- **9月25日12時より前に航空券も宿も取らない**（開始前の予約は応援割の対象外）
