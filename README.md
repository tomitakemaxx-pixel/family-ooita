「行くかどうかを判断する」ための資料を管理する。

| パス | 内容 |

## 現時点の結論（v3・2026年9月23日更新）

- **行く価値はある。** 日程は **11月20日（金）〜22日（日）**（金曜に有給1日、帰宅翌日の11/23が勤労感謝の日）
- **1泊目 別府・杉乃井ホテル（楽天 5547）／2泊目 湯布院・山のホテル 夢想園（楽天 44815）**
- **2日目・3日目だけレンタカー**（別府駅前で借り、大分空港で乗り捨て）にすると、
  湯布院・地獄めぐり・アフリカンサファリが2泊3日に収まる。3泊4日は不要
- **予約開始は 2026年9月25日（金）12:00**（OTA4サイト）。先行した長崎は20分で完売
- 予約は楽天トラベル ANA楽パック「航空券＋宿泊」、2泊目を「宿泊施設変更」で夢想園に。
  レンタカーは楽パックに付けない（ホーバークラフトと両立しないため）
- **9月25日12時より前に航空券も宿も取らない**（開始前の予約は応援割の対象外）
